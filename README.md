# ⚡ Banglish → English Business Assistant (100% JavaScript)

Meta Business Suite ও WhatsApp-এ একাধিক বিজনেসের কাস্টমারকে দ্রুত রিপ্লাই দেওয়ার জন্য তৈরি **PC Global Shortcut (`Alt + Q` / `Alt + W`)** এবং **Mobile & PC Web App (PWA)**।

---

## 🚀 কীভাবে চালু করবেন (PC)

1. প্রজেক্ট ফোল্ডারে থাকা **`Start-App.bat`** ফাইলে ডাবল-ক্লিক করুন (অথবা টার্মিনালে `npm start` দিন)।
2. অ্যাপটি ওপেন হলে উপরের ডান কোণায় **⚙️ Settings** বাটনে ক্লিক করে আপনার ফ্রি **Google Gemini API Key** দিন ([এখান থেকে ফ্রি API Key নিন](https://aistudio.google.com/app/apikey)) এবং **Save Settings** চাপুন।

---

## 💻 পিসিতে জাদুকরী Global Shortcut ব্যবহারের নিয়ম

- **`Alt + Q` (Instant In-Place Convert)**:
  1. WhatsApp বা Meta Business Suite-এর চ্যাট বক্সে সরাসরি Banglish বা বাংলায় লিখুন (যেমন: `apnar order confirm hoyeche, kalke courier e pathabo`)।
  2. লেখাটি সিলেক্ট করুন (`Ctrl + A`) এবং **`Alt + Q`** চাপুন।
  3. ১ সেকেন্ডের মধ্যে আপনার Banglish লেখাটি প্রফেশনাল বিজনেস ইংলিশ হয়ে সরাসরি চ্যাট বক্সে Paste হয়ে যাবে!

- **`Alt + W` (Smart Customer Reply Popup)**:
  1. কাস্টমারের পাঠানো মেসেজটি কপি করুন।
  2. **`Alt + W`** চাপুন—অটোমেটিক কাস্টমারের মেসেজসহ **Customer Reply** উইন্ডো সামনে চলে আসবে।
  3. শুধু ছোট করে Banglish হিন্ট লিখুন (যেমন: `dam 1200 tk, delivery 60 tk`) এবং `Ctrl + Enter` চাপুন—সম্পূর্ণ রিপ্লাই তৈরি হয়ে অটো-কপি হয়ে যাবে!

## 📱 মোবাইলে ব্যবহারের নিয়ম (Mobile PWA)

- **একই Wi-Fi নেটওয়ার্কে**: পিসিতে অ্যাপটি চালু থাকলে **⚙️ Settings**-এ দেখানো Mobile URL (যেমন: `http://192.168.0.72:3847`) মোবাইলের ব্রাউজারে ওপেন করুন এবং ব্রাউজারের মেনু থেকে **"Add to Home Screen"** করে নিন।
- **যেকোনো জায়গা থেকে (4G/5G Mobile Data)**: `public/` ফোল্ডারটি যেকোনো ফ্রি স্ট্যাটিক হোস্টিংয়ে (যেমন **Netlify Drop**, **Vercel**, বা **GitHub Pages**) ড্র্যাগ-অ্যান্ড-ড্রপ করলেই আপনার নিজস্ব অনলাইন অ্যাপ লিংক পেয়ে যাবেন, যা যেকোনো জায়গা থেকে মোবাইলে চলবে!
